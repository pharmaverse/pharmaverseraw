# Exposure as Collected Raw Dataset

A raw dataset used to create pharmaversesdtm::ex

## Usage

``` r
ec_raw
```

## Format

A data frame with 14 columns:

- STUDY:

  Study Identifier

- PATNUM:

  Patient Number

- VISITNAME:

  Visit Name

- FOLDER:

  Folder

- FOLDERL:

  Folder Label

- IT.ECREFID:

  Study Treatment Label Identifier

- DRUGAD:

  Drug Administered

- IT.ECSTDAT:

  Study Treatment Start Date

- IT.ECENDAT:

  Study Treatment End Date

- IT.ECDSTXT:

  Dose of Study Treatment

- IT.ECDOSU:

  Dose Unit of Study Treatment

- DOSFM:

  Dose Form of Study Treatment

- DOSFRQ:

  Dose Frequency of Study Treatment

- IT.ECROUTE:

  Route of Administration
