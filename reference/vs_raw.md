# Vital Signs Raw Dataset

A raw dataset used to create pharmaversesdtm::vs

## Usage

``` r
vs_raw
```

## Format

A data frame with 15 columns:

- STUDY:

  Study Identifier

- PATNUM:

  Patient Number

- INSTANCE:

  Folder

- FORM:

  Form

- FORML:

  Form Label

- VTLD:

  Vital Signs Collection Date

- IT.HEIGHT_VSORRES:

  Height

- IT.WEIGHT:

  Weight

- IT.TEMP:

  Temperature

- IT.TEMP_LOC:

  Temperature Location

- TMPTC:

  Timepoint

- SYS_BP:

  Systolic Blood Pressure

- DIA_BP:

  Diastolic Blood Pressure

- PULSE:

  Pulse

- SUBPOS:

  Subject Position
